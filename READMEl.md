# 📊 CSV 批次轉 Excel 小工具 (CSV to Excel Converter)

這是一個使用 Python 開發的圖形化桌面小工具，專門用來解決日常將 CSV 檔案轉換為 Excel（`.xlsx`）時常見的**中文亂碼**、**前導零消失**以及**無排版**等痛點。程式採用純函式（Function-based）架構撰寫，不使用複雜的類別設計，結構清晰、易於閱讀與後續維護。

---

## ✨ 功能特色

* **目錄掃描與清單勾選**：可自由選擇目標資料夾，自動列出所有 `.csv` 檔案，並支援「全選」、「取消全選」與即時勾選數量統計。
* **雙輸出模式（預設合併）**：
  * **合併為單一 Excel（多分頁）**：將勾選的多個 CSV 檔案整合至同一個 `.xlsx` 檔案中，每個 CSV 獨立成一張工作表（自動清理 Excel 禁用符號、限制 31 字元內並避免重複命名）。
  * **各自轉為獨立 Excel**：將每個勾選的 CSV 各自轉換為對應檔名的 `.xlsx`。
* **自動輸出管理**：轉換後的檔案統一存放在主程式同層目錄下的 `output/` 資料夾（若不存在會自動建立），並內建「開啟 output」捷徑按鈕。
* **智慧編碼與資料保護**：
  * 依序自動嘗試 `utf-8-sig`、`utf-8`、`cp950`、`big5` 編碼讀取，徹底解決中文亂碼問題。
  * 全部欄位預設以純文字（`dtype=str`）讀入，確保店號、編號、電話號碼、郵遞區號開頭的 `0` 不會被吃掉。
* **自動版面美化**：
  * 依據中文字（寬度計 2）與英數字（寬度計 1）自動計算並適配最佳欄寬。
  * 自動套用深藍底白字表頭、凍結首列（方便捲動對照標題）以及開啟自動篩選器。

## 🛠️ 環境需求與安裝

本工具需要 **Python 3.8 以上版本**（內建 `tkinter` 介面模組），並安裝以下兩個第三方套件：

```bash
pip install pandas openpyxl
```

*(註：若在 macOS 或部分 Linux 環境執行時提示缺少 `tkinter`，請依作業系統額外安裝，例如 macOS 可執行 `brew install python-tk`。)*

---

## 🚀 使用方式

1. **啟動程式**：
   在終端機（CMD / PowerShell / Terminal）切換至程式所在目錄並執行：
   ```bash
   python csv_to_excel.py
   ```
   *(請將 `csv_to_excel.py` 替換為您實際儲存的 Python 檔名)*

2. **選擇 CSV 目錄**：
   點擊左上角的 **「📁 選擇 CSV 目錄」**，挑選存放 CSV 檔案的資料夾。

3. **勾選檔案與選擇模式**：
   * 介面會自動列出該目錄下所有 `.csv` 檔案（預設全選），可依需求個別勾選或使用「全選 / 取消全選」。
   * 確認上方的輸出模式（預設為 **「合併為單一 Excel（多分頁）」**）。

4. **一鍵轉換**：
   * 點擊下方的 **「🚀 一鍵轉換為 Excel（存至 output）」**。
   * 轉換完成後會跳出提示視窗，您也可以直接點擊右下角的 **「📂 開啟 output」** 檢視產出的 `.xlsx` 檔案。

## 🧩 程式碼架構說明（維護指南）

主程式由上而下分為三個獨立區塊，方便日後單獨修改或擴充：

1. **核心轉檔區 (`read_csv_auto_encoding`, `format_worksheet`, `convert_*`)**：負責編碼偵測、DataFrame 讀取、工作表命名防呆與 `openpyxl` 樣式排版。此區塊不依賴 GUI，可直接複製供其他自動化爬蟲或排程腳本呼叫。
2. **介面互動區 (`select_folder`, `refresh_file_list`, `start_conversion`, `open_output_folder`)**：負責處理按鈕點擊事件、檔案清單動態產生與轉換流程控制。
3. **視窗排版區 (`root` 初始化)**：使用 `tkinter` 卡片式分區建立視覺介面。
